## Що зроблено
- `TextField` з контролером захоплює введення; кнопка «Застосувати» та
  клавіша Enter ініціюють обробку.
- Валідація винесена в окремий клас `CounterCommand.parse` (sealed-клас):
  - ціле число (зокрема від'ємне) → лічильник збільшується на це число;
  - точний рядок `Avada Kedavra` → лічильник обнуляється;
  - усе інше (текст, спецсимволи, дробові числа, порожнє поле) → стан не
    змінюється, показується `SnackBar` і текст помилки під полем.
- Стан лічильника зберігається у `StatefulWidget` і змінюється через
  `setState()`; значення анімується `AnimatedSwitcher`.
- Строгий `analysis_options.yaml` (шаблон викладача) — 0 зауважень.
- CI: `.github/workflows/validation.yaml` — `dart format`, `flutter analyze`,
  `flutter test` на кожен PR.
- Залишено лише платформи `android/` та `ios/`.
- Тести: юніт-тести парсера + віджет-тест усіх трьох сценаріїв.
